
+ Hướng dẫn chạy bài
  
-Tải Thư viện và Build cho dự án.
  - ở folder chính "midterm" dùng 2 lệnh "npm install" và "flutter pub get" để tải thư viện trước khi chạy bài (có thể dùng "flutter clean" trước khi dùng "flutter pub get").
  - dùng lệnh cd tới folder "function" nhập "npm install" vào terminal để tải các thư viện liên quan về clound function.

-cách chạy bài.
  - dùng lệnh flutter emulators --launch Pixel_4_API_35 và flutter run để chạy app bằng giả lập điện thoại
